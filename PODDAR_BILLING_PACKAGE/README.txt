WINDOWS PAR .EXE BANANE KE LIYE:
═══════════════════════════════════
1. Python install karo: https://python.org (3.10+)
   ✅ "Add Python to PATH" checkbox ZARUR tick karo

2. BUILD_EXE_WINDOWS.bat pe double-click karo
   - Automatically saare libraries install hogi
   - PODDAR_STORES_BILLING.exe ban jayega "dist" folder mein

3. dist\PODDAR_STORES_BILLING.exe — ye aapka final software hai!
   Isko kisi bhi Windows PC pe copy karke run kar sakte ho.

SEEDHA PYTHON SE RUN KARNE KE LIYE:
═════════════════════════════════════
- RUN_DIRECTLY.bat pe double-click karo

SOFTWARE FEATURES:
══════════════════
✅ New Invoice banana (auto invoice number)
✅ Party select karo (dropdown mein 29 parties pehle se hain)
✅ Items select karo (29+ items with HSN, Rate, GST)
